============================================================
  Nova 输入法（便携版）快速上手
============================================================

本文件夹即完整输入法（含词库、引擎、候选窗服务），无需安装程序。

【安装】（约 1 分钟）
  1. 把本文件夹放在任意位置（如 D:\NovaInput），保持文件夹结构。
  2. 右键 install-portable.ps1 → 选择"使用 PowerShell 运行"
     （弹出 UAC 确认窗口，点"是"——TSF 输入法注册需写 HKLM，
      与搜狗/微软拼音一致，只需这一次）。
  3. 看到"安装成功"后，在任意输入框按  Win + Space
     切换到 [Nova 输入法] 即可打字。
  4. 若输入法列表里没有它：
     设置 → 时间和语言 → 语言和区域 → 中文 → 键盘 → 添加键盘 → [Nova 输入法]

【日常使用】
  · Win + Space 或 Alt + Shift 切换输入法
  · 托盘 Nova 图标：双击打开设置面板（候选数/字号/自学习/大字库模式）
  · 用户词库与配置在 %AppData%\NovaInput（引擎实时自学习）

【卸载】
  1. 右键 uninstall-portable.ps1 → 选择"使用 PowerShell 运行"
     （UAC 点"是"）
  2. 删除本文件夹
     （若提示文件占用，注销或重启后再删）
  3. 用户词库/配置保留在 %AppData%\NovaInput，不删除

【常见问题】
  · 文件夹能移动吗？
    能。移动后重新运行一次 install-portable.ps1 即可（注册指向新路径）。
  · 和安装包的差别？
    文件在本文件夹（可移动/可删）；用户数据同样在 %AppData%\NovaInput。
    其余行为（候选窗、自学习、设置面板）完全一致。
  · 杀毒软件提示？
    TSF 输入法需注入宿主进程（与所有输入法相同），个别杀毒可能
    标记 SampleIME.dll，可在杀毒软件中对本文件夹添加信任。
